## 1. 研究量測

- 研究頁面 41% 暗色、59% 亮色；四分之一純白底，12% 純黑底。
- 評審分類：單色加一強調色 23%、淺中性 22%、深中性 14%、多個平色 13%、嚴格雙色 12%、照片承載色彩 9%、單一飽和色域 6%。
- 52% 網站按鈕為黑白灰。彩色按鈕是選擇，非必要。
- 高分站漸層填色 22%，弱站 52%；漸層文字 2% 對 13%。
- 246 站僅一站有陶土色主要按鈕，沒有紫羅蘭色。它們屬生成頁慣用色。32 站用暖灰白底，幾乎都配深色或綠色文字，很少橘色強調。
- 高分站較常在區段換底色，中位兩種區段底色，弱站一種。

## 2. 角色

```css
:root {
  --bg: …;          /* the ground: most of the surface */
  --surface: …;     /* one tone step from the ground: filled panels, form fields, tiles */
  --ink: …;         /* main text and the strongest marks */
  --muted: …;       /* secondary text; still passes contrast on --bg */
  --accent: …;      /* the one accent */
  --accent-ink: …;  /* text on the accent */
  /* --field-1 … --field-n and their inks, when the palette has section fields */
}
```

所有色彩使用 tokens。元件內直接加 hex 等於開始第二套色盤。角色間不另加灰色：次要文字用 `--muted`，低調表面用 `--surface`。

## 3. 比例

上色前決定，截圖中核對：

- **底色：**頁面的 70–90%。
- **文字色：**文字，也可用於一個反相區段，底色與文字色交換。
- **強調色：**每屏低於 5%，標記行動，最多再一種重複元素。出現五處就失去指引意義。

有色域的色盤，如 flat-loud、pastel，每區段使用完整色域，在區段內套比例：色域、對應文字色，不加其他。

除非方向表指定，強調色不用在標題、圖示、項目符號、邊框、底線。標題用文字色。

## 4. 不靠線與陰影的表面

禁線與陰影後，表面只靠色階與底色區分：

```css
.panel { background: var(--surface); }          /* 2–6 lightness points from --bg */
.field { background: var(--surface); border: 0; } /* inputs: filled, with a clear focus state */
.field:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }
```

- 一階就夠。面板不清楚時先增加內距或空間，再考慮第二色階。
- 不在面板內再嵌面板。
- 圖片不需框。淺照片融入淺底就改裁切或放 `--surface`，不描邊。
- 方向有使用時，4px 以上文字色／強調色粗條屬圖形元素，允許；1px 線不行。

## 5. 色域

整個區段換底色是最有力的色彩手法，同時取代分隔線、卡片、背景裝飾。

- 色域邊緣直接相接，不淡化。
- 每色域有色盤指定文字色。不可直接套 `--muted`；次要字可用對應文字色 70% 透明度，但仍須通過對比。
- 相鄰色域明度也要不同，只有色相不同會震動。
- 像章節排序：強烈開場、休止、驚喜、深或極淺收尾。
- 頁面 meta theme 色與導覽跟隨第一色域。

## 6. 暗色頁面

- 根元素設 `color-scheme: dark`，表單與捲軸跟隨。
- 深底帶微量色盤色相，文字柔亮。除非抽到極端雙色，不用 `#fff` 配 `#000`。
- 次要文字常失敗，核對 `--muted` 與底色 4.5:1。
- 深度靠較亮表面階，不靠光暈或彩光。
- 字重比淺色頁輕。

## 7. 色彩與照片

- 照片承載色彩時，介面維持中性，取影像最深色作文字色。
- 不把品牌色洗在照片上。保留原圖，或全頁統一真正處理方式，如全灰階或全原色。
- 圖上文字需要平靜區域，沒有就移出。中性遮罩可用黑或文字色、30–55% 透明度，只覆文字區、平色或淡化；這是檢查器唯一允許的漸層。
- 取照片天空或陰影作平色區段，能與圖協調。

## 8. 對比

- 正文至少 4.5:1；展示字、大數字至少 3:1；抽選色盤的文字／底色達 7:1。
- `inspect.mjs` 量測平底文字，低於 2.6:1 失敗。無法看圖上文字，須自己看截圖。
- 未檢查結果比例前，不降低文字透明度製造柔和感。
- 焦點、懸停增加對比，不降低。

## 9. 禁用色系與此處的暖色定義

檢查器判以下失敗：

- **奶油色加陶土色。** 黃奶油底，約色相 22–62、明亮且有可見飽和度，配鏽、黏土、焦橘，是 AI 助理及生成頁慣用外觀。單獨任一項已可疑，合用更明顯。
- **紫羅蘭與靛藍。** 第一波生成頁以紫色為主，至今仍有此聯想。

需求要暖感時，選低彩度石、骨、灰泥色底，飽和度約低於 15%；深綠、棕、牛血紅文字；照片；或完整平塗的芥末、番茄紅、粉色域。暖感不等於米色。

品牌自有禁色時保留，傳 `--keep palette` 與 `--allow palette-purple` 或適用規則，報告註記。
