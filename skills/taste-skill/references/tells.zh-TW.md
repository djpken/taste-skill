# 生成痕跡：依日期登錄

[英文原文](tells.md) · 翻譯基準：upstream `6010f91`。
[中文索引](../../../README.zh-tw.md#中文文件索引)

生成痕跡是讓頁面看來由模型產生的手法，本身未必壞，多數原是好網站的好構想。到處無理由地預設生產才變成痕跡。因此登錄有日期，不指定替代字型、色彩、元件；每份「改用這個」清單幾個月後都成新痕跡。此處替代的是程序：抽資料庫、從主題推導。

`scripts/inspect.mjs` 與 `scripts/lint.mjs` 偵測大部分。**禁用**代表失敗，**警告**代表標出且須理由。

## 1. 第一波 2023–2024

| 痕跡 | 狀態 | 替代程序 |
| --- | --- | --- |
| 主視覺、按鈕、光暈紫羅蘭／靛藍漸層 | 禁用 | 抽選色盤、平色 |
| 漸層標題文字 | 禁用 | 純文字色 |
| 模糊背景、半透明玻璃卡 | 兩個以上警告 | 與底色差一階的不透明表面 |
| 發光或漸層 Get started | 禁用 | 依行動命名的平面按鈕 |
| 每卡柔灰陰影 | 禁用 | 色階或不加框 |
| 三張相同功能卡、圓角方圖示 | 禁用 | 抽選區段藍圖 |
| emoji 作圖示或項目符號 | 禁用 | 文字、真圖 |
| 置中標題、副標、雙按鈕、下方截圖 | 無規則，抽選避開 | 抽選主視覺 |
| 每生成頁同字型 | 警告，lint: default-font | 抽選字型系統 |

## 2. 第二波 2025

| 痕跡 | 狀態 | 替代程序 |
| --- | --- | --- |
| 每標題上微小大寫加字距眉標 | 禁用 | 合併標題或刪除 |
| 主標上 New、Beta、Introducing 膠囊 | 禁用 | 放輔助句 |
| 標題一詞斜襯線、上色、底線 | 警告 | 同字體同色 |
| 功能區圓角 Bento | 卡片列警告 | 構圖區段；dense-tiles 方向才用實心、嚴格尺寸磚 |
| 近黑底加霓虹強調、光暈 | 依陰影／漸層禁用 | 抽選暗色盤，不發光 |
| 浮動模糊膠囊導覽 | 警告 | 普通橫列 |
| 灰條與甜甜圈假儀表板 | 無規則，見 imagery.md §7 | 真介面片段或無圖 |
| 開放接案、閃爍 live 狀態點 | lint: bounce | 移除 |
| 每區段淡入上移 | 無規則，見 motion.md | 一項招牌動作 |

## 3. 第三波 2025–2026：修法成為新外觀

前兩波的公開修法是「更暖、更像編輯設計」。模型全盤採用，成為最容易認出的生成外觀。

| 痕跡 | 狀態 | 替代程序 |
| --- | --- | --- |
| 黃奶油底加陶土／鏽／黏土強調 | 合用禁用；陶土單用禁；奶油警告 | 抽選色盤，暖感來自低彩度石色、深字色、照片、完整暖色域 |
| 高對比或柔襯線展示字等於高級 | 無規則 | 依抽選字型，不限分類 |
| 超大斜襯線標題 | 無規則 | 依抽選 |
| 報紙扮裝：遍布髮絲線、零圓角、密欄 | 依細線禁用 | 空間與色階建結構 |
| Field notes、Quietly trusted by、On our desks 表演式標籤 | lint: copy | 普通區段名 |

## 4. 作者禁用的展示站潮流

這些在得獎站常見，研究高分比弱站更多：評審觀察等寬標籤 44% 對 24%、索引編號 38% 對 21%；量測細線 61% 對 52%。作者仍禁用，因為生成器最先抄它們，不帶資訊；不用才能找真正結構。

| 痕跡 | 狀態 | 替代程序 |
| --- | --- | --- |
| 等寬微標籤、技術語調、圖說 | 禁用 | 正文字型；資料用等寬數字 |
| 01 / 02 / 03、(001)、Step 02、區段編號 | 禁用 | 位置、尺度、文字，真清單用 `<ol>` |
| 髮絲分隔、格線、1px 外框磚 | 禁用；框三個以上 | 空間、色階、實心形；構想需要時粗條 |
| 十字、裁切、選取框、虛線導引、尺等工具裝飾 | 依細線、虛線禁用 | 移除 |
| 代理商微型 metadata：時間、座標、天氣、版本、版權加捲動、中點字串 | lint: copy；micro-label | 移除 |
| 散落微小大寫加字距圖說 | 三個以上禁用 | 正常句首大寫、可讀字級，與內容相鄰 |

此組只有微小加字距大寫也被資料反對：高分 16%，弱站 57%。

## 5. 結構痕跡

| 痕跡 | 狀態 | 替代程序 |
| --- | --- | --- |
| 完整句當三四行展示標題 | 超兩行禁用 | 約五字詞，其餘放下方 |
| 主視覺、商標、功能、見證、價格、CTA 固定序 | 無規則，copy.md §1 | 依論述 |
| 每區段同版型家族 | critique.md 第 9 輪 | 依表各區段不同 |
| 全置中 | 超 72% 警告 | 靠左，只一次置中 |
| 全用 12–16px 中圓角 | 無 | 直角或全圓，一次決定 |
| 九個相近字級 | 超 9 警告 | 五個、差距大 |
| 虛構商標、引言、星星、10,000+ teams | copy.md §5 | 真證據或不放 |
| 該放圖片卻文字或 CSS 方框 | critique.md 分數上限 | 真圖，或不需圖的設計 |

## 6. 文案痕跡

`lint.mjs` 標示慣用詞 unlock、supercharge、seamless、elevate、effortless、cutting-edge、all-in-one 等；糾正式原文 "not just X, it's Y"；三連標題；Get started、Learn more；過多 em dash；lorem ipsum。見 `copy.md` §6。

## 7. 動態痕跡

每塊相同淡入上移、十幾項主視覺錯開入場、每卡 hover 浮起、bounce、無意義無限循環、揭示失敗留下空帶。見 `motion.md` §9。

## 8. 只移除仍不足

移除所有痕跡卻不補內容，就是有禮貌的空頁，也是一種痕跡：只憑類別與禁用清單就能猜出的「迴避美學」。痕跡原本填補構想空缺。`SKILL.md` 流程先補空缺：主題構想、抽選構圖、真圖或堅定文字，最後才檢查。
